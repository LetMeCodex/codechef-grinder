# [Ordered Distances (ORDDIST)](https://www.codechef.com/problems/ORDDIST)
- **Difficulty Rating**: 1112
- **Solved in**: 1 attempt(s)

## Problem Summary

The problem asks us to find a specific element `P` from a given array `X` that, when used as a "pivot," generates another given array `Y`. The generation process is as follows:

1.  Choose an element `P = X[k]` from the array `X` (where `k` is its 0-based index).
2.  For every element `X[j]` in `X`, create a pair `(distance, value)`, where `distance = abs(X[j] - P)` and `value = X[j]`.
3.  Sort these `N` pairs. The primary sorting key is the `distance`. If two pairs have the same `distance`, the secondary sorting key is the `value` itself.
4.  After sorting, form a new array `Y_candidate` by taking the `value` (second element) from each sorted pair, in order.
5.  The problem states that the given array `Y` is exactly this `Y_candidate` generated by some `X[k]`. We need to find the 1-based index `k+1` of this `X[k]`. If no such `X[k]` exists, output -1. It's guaranteed that if a solution exists, it's unique.

## Intuition & Mathematical Observation

The core of the problem lies in understanding the generation process of `Y`. Since `N` (the size of the arrays) is relatively small (up to 1000), we can simulate the process for every possible choice of `P`.

Here's the step-by-step intuition:

1.  **Iterate through all possible pivots:** Since `P` must be one of the elements in `X`, we can try each `X[k]` (for `k` from `0` to `N-1`) as our potential pivot `P`.
2.  **Simulate the generation for each `P`:**
    *   For a chosen `P = X[k]`, we need to construct the list of pairs `(abs(X[j] - P), X[j])` for all `j`.
    *   Once these pairs are formed, we sort them. A crucial observation here is that `std::pair`'s default comparison behavior perfectly matches the problem's sorting criteria: it first compares the `first` elements (distances), and if they are equal, it then compares the `second` elements (values). This simplifies the sorting step significantly.
    *   After sorting, we extract the `value` (second element) from each pair to form our `Y_candidate` array.
3.  **Compare and find the match:** We then compare this `Y_candidate` with the given `Y` array. If they are identical, we have found the correct pivot `X[k]`. We record its 1-based index (`k+1`) and stop, as the problem guarantees a unique solution.
4.  **Handle no match:** If we iterate through all possible `X[k]` and don't find a match, it means no such pivot exists, and we output -1.

This brute-force simulation approach works because `N` is small enough to allow `N` iterations, each involving sorting `N` elements.

## Complexity Analysis

*   **Time Complexity**: $O(N^2 \log N)$
    *   We iterate `N` times, once for each possible pivot `X[k]`.
    *   Inside each iteration:
        *   Creating `N` pairs `(abs(X[j] - P), X[j])` takes $O(N)$ time.
        *   Sorting these `N` pairs takes $O(N \log N)$ time.
        *   Extracting `N` values to form `Y_candidate` takes $O(N)$ time.
        *   Comparing `Y_candidate` with `Y` takes $O(N)$ time.
    *   Summing these up, each iteration takes $O(N \log N)$ time.
    *   Total time complexity: $N \times O(N \log N) = O(N^2 \log N)$.
    *   Given `N <= 1000`, $1000^2 \log_2 1000 \approx 10^6 \times 10 = 10^7$ operations, which is well within typical time limits (usually $10^8$ operations per second).

*   **Space Complexity**: $O(N)$
    *   We store the input arrays `X` and `Y`, each of size `N`.
    *   Inside the loop, we create a `vector<pair<int, int>> L` of size `N` and a `vector<int> Y_candidate` of size `N`.
    *   All these data structures require $O(N)$ space.
    *   Given `N <= 1000`, this is a very small amount of memory (e.g., a few kilobytes), well within typical memory limits.

## Solution Code

```cpp
#include <bits/stdc++.h> // Includes iostream, vector, cmath, algorithm, utility, etc.

// Use standard namespace as requested
using namespace std;

void solve() {
    int N;
    cin >> N;
    vector<int> X(N);
    for (int i = 0; i < N; ++i) {
        cin >> X[i];
    }
    vector<int> Y(N);
    for (int i = 0; i < N; ++i) {
        cin >> Y[i];
    }

    int found_pivot_index = -1; // Initialize to -1, indicating no pivot found yet

    // Iterate through each possible pivot X[k] (0-indexed)
    for (int k = 0; k < N; ++k) {
        int P = X[k]; // The pivot value for the current iteration
        
        vector<pair<int, int>> L;
        L.reserve(N); // Pre-allocate memory for efficiency, avoiding reallocations

        // Populate list L with (distance, value) pairs
        // distance = abs(X[j] - P)
        // value = X[j]
        for (int j = 0; j < N; ++j) {
            L.push_back({abs(X[j] - P), X[j]});
        }

        // Sort L according to the problem's criteria.
        // std::pair's default comparison works exactly as required:
        // first by first element (distance), then by second element (value) if first elements are equal.
        sort(L.begin(), L.end());

        // Construct the candidate Y sequence from the sorted pairs
        vector<int> Y_candidate(N);
        for (int j = 0; j < N; ++j) {
            Y_candidate[j] = L[j].second; // Take the 'value' part of the pair
        }

        // Compare Y_candidate with the given Y
        bool match = true;
        for (int j = 0; j < N; ++j) {
            if (Y_candidate[j] != Y[j]) {
                match = false;
                break; // Mismatch found, no need to check further elements
            }
        }

        if (match) {
            found_pivot_index = k + 1; // Pivot index is 1-based as per problem statement
            break; // Found a valid pivot, no need to check other pivots (solution is unique)
        }
    }

    cout << found_pivot_index << "\n"; // Output the 1-based index or -1
}

int main() {
    // Fast I/O setup to speed up input/output operations
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int T;
    cin >> T; // Read the number of test cases
    while (T--) {
        solve(); // Solve each test case
    }

    return 0;
}
```
